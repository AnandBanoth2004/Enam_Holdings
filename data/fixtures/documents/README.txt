FINN SYNTHETIC DOCUMENT FIXTURES

The seven text files in this directory are fabricated structures for database
and UI testing: four illustrative quarterly-result examples, an annual-report
outline, a transcript outline, and an investor-presentation outline. They are
NOT primary-source company documents, exchange filings, or company-reported
data. Names/tickers only exercise issuer mapping. No values or text in these
files may be described as actual company performance, guidance, or disclosure.
