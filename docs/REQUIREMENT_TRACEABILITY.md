## Announcement taxonomy coverage (17/17)

Taxonomy definitions are from Reference page 1. The main brief says the reference classification is guidance and may be adapted or ignored; this proposal chooses to account for every label to avoid gaps.

| Label | Reference meaning (short) | Proposed prototype treatment |
|---|---|---|
| `results` | Quarterly/annual results, board approval, decks, letters, publication ads | High priority; structured headline metrics and QoQ/YoY when supported by filings |
| `M&A` | Acquisition, merger, demerger, JV, subsidiary investment/stake sale | High priority; summary plus network expertise match |
| `fund_raise` | Rights, QIP, preferential allotment, buyback, commercial paper/debt | Prioritized; identify amount/instrument if filing supports it |
| `management_change` | CEO/CFO/MD/director joining, resigning, retiring | High priority; incoming-person bio and network overlap |
| `litigation` | Lawsuits, regulatory orders, fines, warnings, insolvency/restructuring | High priority; summary, primary filing, relevant contact |
| `insider_trading` | Promoter/insider personal shareholding purchase/sale | Prioritized; surface direction/quantity if available |
| `earnings_call` | Investor call notice, transcript, recording link | Useful/medium; link transcript into Pull |
| `investor_meetings` | One-on-one/small-group investor meetings or conferences | Medium; surface filing with concise context |
| `credit_rating` | Rating assigned, upgraded, downgraded, reaffirmed | High/medium; capture direction and rating agency if present |
| `dividend` | Cash dividend and record date | Medium; show amount and record date |
| `bonus_split` | Bonus issue or stock split | Medium; explain share count changes, no cash payout |
| `capex` | New plant/facility/capacity expansion spend approval | High when material; show amount/timing and network match |
| `press_release` | General order/product/partnership/rumour clarification | Medium; concise summary, evidence link |
| `postal_ballot` | Postal-ballot notice/result | Low/medium; show subject and key date/result |
| `agm_egm` | Annual/extraordinary meeting notice/result | Low/medium; show material agenda/date/result |
| `pledging` | Promoter pledge/release/status change | High/medium; show change and source |
| `unclassified` | Routine low-relevance paperwork (e.g. ESOP, compliance, ESG, auditor appointment) | Collapsed/low by default; still findable in full digest |

## Financial calculation policy for implementation

1. Use **reported values** for Revenue, EBITDA, PBT, and PAT from primary company/exchange filings. Do not silently substitute a differently defined “operating profit” for EBITDA.
2. For a metric and company, compare the same reporting basis (standalone or consolidated), currency, and units. Do not combine bases to fill a missing quarter.
3. QoQ comparison is current quarter against the immediately previous quarter; YoY is against the same quarter one year earlier.
4. For a percentage change, use `(current - comparison period) / abs(comparison period) × 100` when a non-zero comparison base makes it meaningful. Where the base is zero/negative or the measure makes percentage change misleading, show the absolute change and explain why percentage change is not meaningful.
5. EBITDA margin is `EBITDA / Revenue × 100`. Apply only when Revenue is present and non-zero.
6. D/E is `total debt / shareholders' equity`; FCF is `cash from operations - capital spending`. State the chosen source line items. The reference does not prescribe a universal cash-conversion, working-capital-cycle, ROCE, or ROE calculation, so label the convention if used.
7. Every extracted/calculated value should retain source document, period, page/table or excerpt, units, and whether it is reported or derived. Missing/ambiguous data should be shown as unavailable, not inferred.
